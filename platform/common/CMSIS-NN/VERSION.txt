Notes
-----
- Self-contained: CMSIS-NN (>= v4.0) depends only on CMSIS-Core, NOT on CMSIS-DSP.
  No source under Source/ or Include/ includes arm_math.h, so CONFIG_CMSIS_NN does
  not need to enable CONFIG_CMSIS_DSP.
- Reserved as the optimized backend for a future TensorFlow Lite for
  Microcontrollers (TFLM) integration.
- Upstream build files (top-level and per-module CMakeLists.txt, ARM.CMSIS-NN.pdsc,
  Makefiles, gen_pack.sh, Documentation/, Examples/, Tests/) were removed; the
  library is built by components/platform/common/CMakeLists.txt via CONFIG_CMSIS_NN
  (all Source/*.c globbed).
- Kernel path is auto-selected from the compiler's __ARM_FEATURE_DSP (set via -mcpu):
  cortex-m3 -> scalar C path, cortex-m33 -> DSP-extension SIMD path. Standard
  Cortex-M33 has no Helium/MVE, so the MVE kernels are not used. No ARM_NN_* or
  ARM_MATH_* defines are required.
- This v7.0.0 package ships no float16 kernels, so (unlike CMSIS-DSP) there is no
  F16 module to exclude.
