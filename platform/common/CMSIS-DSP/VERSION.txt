Notes
-----
- The per-file "@version" doc stamps inside the headers (e.g. V1.10.0) are stale
  upstream markers and do NOT reflect the package version. The authoritative
  version is the release tag above.
- Upstream build files (CMakeLists.txt / Makefile / configDsp.cmake) were removed;
  the library is built by components/platform/common/CMakeLists.txt via
  CONFIG_CMSIS_DSP (16 module consolidation .c files; F16 modules are not
  compiled).
- Core/FPU path is auto-selected from the compiler's __ARM_FEATURE_DSP / __ARM_FP
  (set via -mcpu); no ARM_MATH_* defines are required for CMSIS-DSP >= 1.15.
